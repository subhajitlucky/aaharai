# Authoring format

Copy this file to `<slug>.mdx` and replace every angle-bracket token before publication. A file containing any angle-bracket token is an incomplete draft and must not enter the public catalog.

Use the shared sourced recipe contract. Keep the filename stem equal to `slug`, choose one `trustLabel` that matches `provenance`, and list only source IDs that exist in `content/sources/index.json`. Do not use `community-tested` unless a real community test occurred and is documented.

Use normalized ingredient IDs from `content/foods/ingredients.json`. Every nutrition number needs a registered source ID and an explicit `estimated` value. State the calculation basis and keep estimates honest when a recipe has not been laboratory measured.

Record the state or union territory, a month-based season window, method, variations, substitutions, cost tier, dietary tags, and the actual review date in the frontmatter. The body is plain text: it is not an MDX execution surface.
